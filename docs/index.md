# Drummer

Drummer investigates what a conversation can leave unsaid without losing what
the recipient needs. It contains a small communication model trained from random
initialization and a separate exact protocol for coding-agent handoffs.

The first experiment asks whether a model can learn when a previously established
referent is still shared. It does not establish general language, compositionality,
experienced emotion, or savings in real coding work.
